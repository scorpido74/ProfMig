# Code of Conduct

## Our Pledge

We as contributors and maintainers pledge to make participation in the ProfMig community a welcoming, respectful and harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity, level of experience, nationality, personal appearance, race, religion or sexual identity and orientation.

Our goal is to create a professional, inclusive and collaborative environment where everyone feels comfortable contributing.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and professional.
- Giving and accepting constructive feedback.
- Being patient with new contributors.
- Helping others learn.
- Respecting different viewpoints and experiences.
- Focusing on what is best for the project.
- Taking responsibility for mistakes and learning from them.

Examples of unacceptable behavior include:

- Harassment or personal attacks.
- Offensive or discriminatory language.
- Trolling or deliberately disruptive behavior.
- Publishing private information without permission.
- Repeatedly ignoring project guidelines.
- Spam or abusive communication.

---

# Our Development Philosophy

ProfMig is built around the following principles:

- Reliability
- Simplicity
- Transparency
- Maintainability
- Security

Every contribution should support these goals.

---

# Community Expectations

We encourage contributors to:

- Ask questions.
- Share ideas.
- Report bugs.
- Suggest improvements.
- Review code respectfully.
- Help improve documentation.

Everyone starts somewhere. Be patient and helpful.

---

# Maintainer Responsibilities

Project maintainers are responsible for:

- Reviewing contributions fairly.
- Providing constructive feedback.
- Maintaining a respectful environment.
- Applying this Code of Conduct consistently.
- Making decisions that benefit the project as a whole.

Maintainers may edit, reject or remove comments, commits, issues or pull requests that violate this Code of Conduct.

---

# Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- GitHub Discussions
- Pull Requests
- Project Wiki
- Documentation
- Community communications

It also applies when representing ProfMig in public.

---

# Reporting Issues

If you experience unacceptable behavior, please open a private discussion with one of the project maintainers.

Current maintainers:

- Remco de Kievit (@scorpido74)
- baseman-dev

All reports will be handled confidentially whenever possible.

---

# Enforcement

Project maintainers may take any action they consider appropriate, including:

- Warning a contributor.
- Removing comments.
- Closing issues.
- Closing pull requests.
- Temporarily restricting participation.
- Permanently banning users from the project.

The goal is always to maintain a professional and respectful community.
